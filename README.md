# Flores & Eventos — Florería y decoración de eventos

Sitio web one-page para un emprendimiento de florería y decoración de eventos (inauguraciones, bodas, quinceañeros).
Construido con Astro + Tailwind CSS 4, desplegado en Vercel.

> El nombre comercial "Flores & Eventos" es provisional (la clienta no lo indicó). Cambiar en `src/data/site.ts`.

- Catálogo con precios referenciales y filtro (arreglos / eventos)
- Cotización directa por WhatsApp (+51 916 973 823) con mensajes prellenados
- Galería de eventos y proceso de cotización
- SEO: Open Graph, JSON-LD (Florist), sitemap

## Desarrollo

```bash
npm install
npm run dev
npm run build
```

Contenido en `src/data/site.ts` y `src/data/products.ts`. Imágenes en `public/img` (WebP).
